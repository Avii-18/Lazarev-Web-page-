## 🎯 About the Project

This project is a creative agency-style website designed to explore modern frontend development and advanced animation techniques.

It features a dark visual theme, interactive cards, animated navigation, scrolling effects, and a large typography-based footer. GSAP is used to create engaging transitions and scroll-triggered animations.

The project demonstrates how HTML, CSS, and JavaScript can be combined with animation libraries to build visually appealing web experiences.

> **Note:** This is an independent learning project inspired by modern agency websites. It is not an official Lazarev.agency website.

## 📚 Libraries and Resources

### 1. GSAP — GreenSock Animation Platform
Website: https://gsap.com/

Used for creating smooth animations, timeline sequences, element transitions, and interactive effects.

### 2. GSAP ScrollTrigger
Documentation: https://gsap.com/docs/v3/Plugins/ScrollTrigger/

Used to trigger animations when elements enter or leave specific scroll positions.

### 3. Locomotive Scroll
GitHub: https://github.com/locomotivemtl/locomotive-scroll

Used for smooth scrolling effects. Compatibility and setup depend on the version used in the project.

### 4. Remix Icon
Website: https://remixicon.com/

An icon library that can be used for navigation icons, arrows, and interface elements.

### 5. Google Fonts

### 6. MDN Web Docs

## ⚙️ Installation and Setup

### Prerequisites

Before running the project, make sure you have:

- A modern web browser, such as Google Chrome.
- Visual Studio Code or another code editor.
- The Live Server extension for VS Code (recommended).
- An internet connection if external CDN libraries or online fonts are used.

### Clone the Repository

Open your terminal and run:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate into the project folder:

```bash
cd creative-agency-website
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

---

## ▶️ How to Run

1. Open the project folder in Visual Studio Code.
2. Make sure the HTML, CSS, JavaScript, and asset paths are correct.
3. Install the Live Server extension if you have not already.
4. Open `index.html`.
5. Click **Go Live** in VS Code.
6. View the website in your browser.

If your project uses CDN links, make sure you have an internet connection.

## 🎬 Animation Details

### GSAP Timeline Animations

GSAP timelines are used to sequence animations, allowing multiple elements to animate in a controlled order.

### ScrollTrigger Animations

ScrollTrigger can start, scrub, or synchronize animations with the user's scroll position.

### Navigation Animations

Navigation elements can use transitions and animated movement to create a more engaging menu experience.

### Interactive Card Effects

JavaScript event listeners can detect card clicks and hover interactions, while CSS transitions and GSAP can add movement and visual feedback.

### Animated Logo Ticker

CSS keyframes can create a continuously moving row of technology logos or partner icons.

### Creative Footer

The footer uses oversized typography, accent colors, navigation links, and hover transitions to create a strong visual ending.
